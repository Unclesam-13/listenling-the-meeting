# 会议助手 Meeting Copilot（Mac）

电脑开会，手机看答案：实时转写会议（中英混合）、区分说话人、识别对方的提问，自动在你准备的资料库里找答案，以「一句话结论 + 要点 + 出处」的形式推送到手机。

全部使用云端 API，**不需要下载任何模型**，安装只要几分钟。

```
麦克风（我）  ─┐                                                           ┌─> 电脑页面
               ├─> Soniox 实时识别（中英混说 + 区分说话人 + 自动断句）─> 意图识别 ─> 资料库 ─> Claude 生成回答 ─┤
系统声音（对方）┘                                         (Claude / Jev / 规则)                  └─> 手机（扫码）
```

需要的 API Key（都在页面「设置」里填写）：

| 用途 | 服务 | 获取 | 是否必需 |
|---|---|---|---|
| 语音识别 | [Soniox](https://soniox.com) | https://console.soniox.com | 必需（约 0.12 美元/小时） |
| 根据资料回答问题 | Claude / ChatGPT / DeepSeek | [Claude](https://console.anthropic.com) · [OpenAI](https://platform.openai.com/api-keys) · [DeepSeek](https://platform.deepseek.com/api_keys) | 至少一个 |
| 判断对方是否在提问 | 大模型（同上）或 [Jev](https://jevmodel.org/zh/dashboard/) | — | 可选 |

可以在设置里选择用哪个模型回答；选中的模型出错或没填 Key 时，会自动换用其他已填 Key 的模型。
其他兼容 OpenAI 格式的模型（如通义千问）可以在 config.yaml 的 `llm.providers` 里添加。

## 手机版（不需要电脑）

手机打开 **https://unclesam-13.github.io/listenling-the-meeting/** 即可使用，iPhone（Safari）和安卓（Chrome）都可以，建议"添加到主屏幕"当 App 用。

- **实时字幕 + 中英互译**：中文发言下面显示英文，英文发言下面显示中文（也可以设成全部翻成中文 / 英文，或关闭）
- **区分说话人**：点名字可以改名，或标记"这是我"（我说的话不会触发自动回答）
- **自动回答**：识别到对方提问时，根据你上传的资料给出「结论 + 要点 + 来源」
- **会议总结**：点「结束」后自动生成会议摘要、关键决定、待办事项、对方的问题和待跟进事项，可以复制、分享、导出全文（含翻译）
- **会议记录**：每场会议都保存在手机上，随时打开查看或重新生成总结
- **资料库**：在设置里直接上传 .pdf .docx .md .txt，或直接粘贴文字
- **资料预先整理**：添加资料后，AI 在后台把每段资料整理成摘要、中英文关键词和"对方可能会问的问题 + 简短答案"；填了 ChatGPT Key 时还会生成向量。开会时先查这个索引（在手机本地完成，几乎不花时间），问题对得上时先显示预备答案；索引里找不到，或者根据索引答不出来，再自动去原文里检索

注意：
- 开会时请保持这个页面在前台、屏幕亮着（程序会尽量让屏幕常亮）；切到其他 App 或锁屏时，手机系统会暂停录音
- 手机录不到同一部手机上会议 App 里对方的声音，适合线下会议，或者用电脑/其他设备外放开会
- 所有 Key、资料和会议记录只保存在这部手机的浏览器里；清除浏览器数据会一并删除
- 手机版直接从浏览器调用各家接口：Claude、ChatGPT 支持这种方式；DeepSeek 和 Jev 如果不支持，页面会提示，并自动换用其他已填 Key 的模型

手机版代码在 `mobile/`，每次修改后由 GitHub Actions 自动测试并发布（`.github/workflows/mobile-pages.yml`）。

## 下载安装（推荐：DMG）

1. 到 [Releases](https://github.com/Unclesam-13/listenling-the-meeting/releases/latest) 下载 DMG：Apple 芯片（M1 及以后）选 `AppleSilicon`，Intel 芯片选 `Intel`
2. 打开 DMG，把「会议助手」拖进「Applications」
3. 第一次打开会被系统拦截（应用未经 Apple 公证）：去「系统设置 → 隐私与安全性」，点「仍要打开」
4. 出现「会议助手」窗口（独立窗口，不经过浏览器）；在弹出的「设置」里填写两个 API Key，并选择麦克风和 BlackHole
5. 安装免费的 [BlackHole 2ch](https://existential.audio/blackhole/)，并建好多输出设备（见下文）

资料库、配置和日志都在 个人文件夹/会议助手 里，屏幕顶部的「会议助手」菜单可以一键打开。关闭窗口即退出。

DMG 由 GitHub Actions 在云端 Mac 上自动打包（`.github/workflows/build-dmg.yml`），推送 `v*` 标签即发布新版本。

## 快速开始（不用 DMG，用脚本安装）

1. 下载并解压 zip 包
2. 双击 **安装.command**：自动安装所需软件，并让你粘贴上面两个 API Key（约 3–5 分钟，只需一次）
3. 按安装结束时的提示，在「音频 MIDI 设置」里建好多输出设备（见下文）
4. 以后每次开会，双击 **启动会议助手.command**，然后用手机扫电脑页面上的二维码

> 第一次双击时如果提示"无法打开，因为来自身份不明的开发者"：右键点该文件 →「打开」→ 再点「打开」。
> 如果提示"没有权限"：打开终端，输入 `cd `（cd 加一个空格），把解压出来的文件夹拖进终端窗口，回车，然后运行 `chmod +x *.command`。

### 让电脑既能听到声音，又能把声音录下来

1. 打开「音频 MIDI 设置」（应用程序 > 实用工具）
2. 左下角「+」→「创建多输出设备」
3. 勾选你的耳机/扬声器 **和** BlackHole 2ch；耳机/扬声器设为「主设备」，BlackHole 勾选「漂移校正」
4. 在 Zoom / Teams / 腾讯会议 的音频设置里，把**扬声器**选成这个多输出设备

> 建议戴耳机开会：否则对方的声音会从扬声器漏进你的麦克风，被识别成「我」说的话。
> 使用多输出设备时，键盘音量键可能不起作用，需在会议软件里调音量。

**线下会议**：把 config.yaml 里的 `system_device` 改成 `null`，只用一个麦克风录全场，由 Soniox 区分不同的人。

## 使用

- **开始 / 结束**：打开程序后默认不录音、不连接识别服务。开会时点左上角「● 开始」，会议结束点「■ 结束」，结束后立即断开，不再计费。手机上也有同样的按钮。忘了点结束也没关系：连续 10 分钟没人说话会自动结束（`audio.auto_stop_minutes` 可调，0 为关闭）
- 电脑页面：左边是实时转写（灰色是正在说的话），中间是回答，右边是二维码和说话人列表（点名字可以改名，比如把"对方1"改成"王总"）
- 手机页面：最新的回答显示在最上面，也可以直接在手机上提问
- 不开会时测试：在终端运行 `./启动会议助手.command --no-audio`，然后在电脑页面左下角「模拟对方」说一句话

### 准备资料库

把资料放进 `knowledge/` 文件夹（支持 `.md` `.txt` `.pdf` `.docx`，可以有子文件夹），然后在电脑页面点「重新加载资料库」。

- 资料总量不大时（默认 15 万字以内），全部资料会直接交给 Claude 阅读，回答最准确；启用了提示词缓存，同一场会议里后续提问会更快、更便宜
- 资料较多时，自动改为关键词检索：Claude 会先把问题扩展成中英文关键词，所以中文问题也能找到英文资料
- 写资料时用标题分好节（Word 用标题样式、Markdown 用 `#`），常见问题可以直接写成「问：… 答：…」

### 提高识别准确率

在 config.yaml 里填：
- `asr.terms`：你们行业的专有名词、产品名、人名，例如 `[Kubernetes, ARR, 毛利率]`
- `asr.context_text`：一句话描述会议背景

## 用 Jev 判断是否在提问

Jev 是决策模型：对每段发言返回「是在向我提问」的概率和发言类型（提问 / 请求 / 质疑 / 陈述 / 寒暄），速度快、成本低。它不生成文字，所以回答仍由上面选的大模型负责。

- 在设置里把「判断对方是不是在提问」选成 **Jev**，填 Jev API Key（[jevmodel.org 控制台](https://jevmodel.org/zh/dashboard/)）
- 想先看看效果，可以选 **以大模型为准，同时对比 Jev**：两边的判断和耗时都记录在 `logs/intent_compare.jsonl`
- 默认接口 `https://jevmodel.org/v1/systemone`，模型 `jev-latest`，概率超过 0.6 才回答（`intent.jev.threshold`）
- Jev 出错（Key 无效、余额不足等）时自动退回规则判断，并在页面顶部显示原因

> 注意：jevmodel.org 声明自己是独立网站，与 Jev 的开发商 TypeSafe AI 无关，运营方未公开；启用后，对方的发言会发送给它。它的接口格式与 TypeSafe 官方 SystemOne 接口相同，以后切换只需在设置里改接口地址和 Key。

## 常用参数（config.yaml）

| 参数 | 作用 | 建议 |
|---|---|---|
| `asr.max_endpoint_delay_ms` | 一句话结束后多久确认 | 对方说话慢可调大 |
| `intent.settle_ms` | 对方停顿多久才判断是否在提问 | 回答出现得太早就调大，太慢就调小 |
| `intent.answer_for` | `others` 只回答对方 / `all` 也回答自己 | |
| `llm.answer_provider` | 回答用 `claude` / `openai` / `deepseek` | 设置页面里也能改 |
| `llm.providers.*` | 各家的模型名称和接口地址 | 模型更新后在这里改名称 |
| `kb.mode` | `auto` / `full` / `search` | 一般保持 auto |

## 项目结构

```
安装.command / 启动会议助手.command   双击安装 / 启动
run.py              启动入口
config.yaml         配置
.env                API Key（安装时生成，不会上传到 GitHub）
app/audio.py        两路录音
app/asr.py          Soniox 实时识别
app/speakers.py     说话人名单
app/intent.py       意图识别（Claude / Jev / 规则，可切换）
app/kb.py           资料库
app/brain.py        生成回答
app/server.py       服务端、推送到电脑和手机、扫码
app/web/            电脑页面、手机页面
knowledge/          你的资料
```

## 注意

- 手机链接带有一次性令牌，每次启动都会变，只有扫到码的设备才能查看。电脑页面只能在本机打开。
- 会议音频会实时发送给 Soniox 识别；转写内容和资料会发送给 Claude（以及启用后的 Jev）。请确认这符合你们公司对会议内容和资料的保密要求。
- 录音和转写他人的发言前，请按当地法律告知并征得参会者同意（在新南威尔士州通常需要各方同意）。
