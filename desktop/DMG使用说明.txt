会议助手（Mac 版）使用说明
==========================

【安装】
把「会议助手」拖到右边的「Applications（应用程序）」文件夹。

【第一次打开】
这个应用没有经过 Apple 公证，第一次打开会被系统拦截：
  1. 在「应用程序」里双击「会议助手」，出现提示后点「完成」
  2. 打开「系统设置」→「隐私与安全性」，往下拉，找到"已阻止打开会议助手"，点「仍要打开」
  3. 再次打开，输入电脑密码确认
之后就可以正常双击打开了。第一次点「开始」时系统会询问是否允许使用麦克风，请点「允许」。

如果提示"已损坏，无法打开"：打开「终端」，输入下面这行后回车，再打开即可：
  xattr -cr /Applications/会议助手.app

【填写 API Key】
点右上角「设置」：
  · Soniox API Key（语音识别 + 实时翻译）：https://console.soniox.com
  · 回答问题用的大模型，至少填一个：
      Claude：https://console.anthropic.com
      ChatGPT：https://platform.openai.com/api-keys
      DeepSeek：https://platform.deepseek.com/api_keys
  · （可选）Jev：更快地判断对方是不是在提问：https://jevmodel.org/zh/dashboard/
  · 资料库：添加 PDF、Word、Markdown、TXT，或直接粘贴文字
所有 Key、资料和会议记录只保存在这台电脑上。

【录到会议软件里对方的声音（只需设置一次）】
1. 安装免费的虚拟声卡 BlackHole 2ch：https://existential.audio/blackhole/
2. 打开「音频 MIDI 设置」（应用程序 > 实用工具），点左下角「+」→「创建多输出设备」
3. 勾选你的耳机/扬声器 和 BlackHole 2ch；耳机/扬声器设为主设备，BlackHole 勾选「漂移校正」
4. 在 Zoom / Teams / 腾讯会议 的扬声器设置里，选这个「多输出设备」
5. 回到会议助手：设置 →「录音（Mac）」→「会议软件里对方的声音」选 BlackHole 2ch
之后你说的话标成"我"（不会触发自动回答），会议里对方的话照常区分说话人。
建议戴耳机开会，避免对方的声音漏进你的麦克风。
线下会议：「会议软件里对方的声音」选「不录」，用一个麦克风录全场。

【开始 / 结束】
打开软件不会自动录音。开会时点「开始」，结束点「结束」，结束后立即断开语音识别，不再计费，
并自动生成会议总结。忘了点结束的话，连续 10 分钟没人说话会自动结束。

【同声传译】
顶部菜单「功能 → 同声传译」（⌘2），回到会议助手按 ⌘1。

【退出】
关闭窗口或按 ⌘Q。正在录音时关闭会先询问。
